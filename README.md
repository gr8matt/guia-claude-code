# Guía Claude Code

A bilingual (Spanish/English) single-page guide for getting started with Claude Code. It's built as an installable web app, and its examples come from Lompoc Foursquare Church.

Live: https://danrivas.jalamatech.com

- Plain HTML/CSS/JS with no build step. Open `index.html` or run `python3 -m http.server`.
- Language toggle: elements with class `es` / `en` are shown or hidden based on `<html lang>`.
- Hosted on GitHub Pages. The custom domain is set in `CNAME`.
